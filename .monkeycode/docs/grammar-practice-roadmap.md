# 语法练习分级路线（P1 书面阶段已实施）

## 已实施（P1，书面阶段）

- 级别壳：A1 / A2 / B1 / B2 / C1 / 专八附加，`GrammarPracticeScreen` 顶部切换
- 板块来源两类：
  1. **本地资产即时生成**（难度由词书分级 + 变位引擎锚定）：冠词性数、动词变位（现在/未完成/简单将来/命令式/条件式/复合过去/虚拟式未完成）、词汇释义选择
  2. **AI 预生成静态题库**（`GrammarBankA1/A2/B1/B2/C1/Tfs8.kt`，已逐题校对）：否定、代词、比较级、关系代词、虚拟式、间接引语、被动产词、复合关系代词、语域、强调倒装、文学时态、名词化、高阶辨析
- 专八附加书面专项：完形填空、阅读理解、法译汉、汉译法、同义词替换、句子改错、文学文化常识、写作手法
- 原「六大板块」保留为不分级别的综合练习区
